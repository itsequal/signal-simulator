# Simulador de modulaciones digitales binarias

## Requisitos

- Node.js 24 

## Inicializacion

```bash
npm ci
npm run dev
```

Abre la dirección que muestra Vite (incluye la ruta base si defines `BASE_PATH`). El micrófono exige HTTPS o `localhost`; abrir `index.html` con `file://` no sirve.

```bash
npm test
npm run lint
npm run build
npm run e2e
```
